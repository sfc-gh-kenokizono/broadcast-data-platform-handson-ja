# 第3章 MLOps体験: モデルを学習・登録・予測する

第2章で作成した視聴データから、テレビに対応する世帯にF1層（20〜34歳の女性）がいる確率を予測します。

この章では、次のSnowflake MLの流れを体験します。

```text
データ準備
  ↓
ロジスティック回帰モデルを学習・評価
  ↓
Model Registryへ登録
  ↓
登録したモデルで20,000台を予測
  ↓
予測結果をSnowflakeへ保存
```

すべて教材用の合成データです。実在する個人の属性や人数を示すものではありません。

## 1. Notebookを接続する

Git Workspaceで `notebooks/03_mlops.ipynb` を開きます。Notebook上部の接続メニューを開き、次の値を選びます。

| 設定 | 選ぶ値 |
|---|---|
| Compute type | CPU |
| Python | 3.12 |
| Runtime | `v2.10` |
| Artifact repository | 画面に表示されるSnowflake管理のPyPI repository |
| Compute pool | `SYSTEM_COMPUTE_POOL_CPU (CPU_X64_S)` |
| Idle timeout | 24時間 |

Custom imageは選択せず、**Create and connect** を押します。

**成功の目印:** Notebook上部が接続済みになります。

## 2. セルを上から順に実行する

Notebookには6つのコードセルがあります。各Markdown説明の直後にあるコードセルを、上から1つずつ実行します。

### セル1: Notebookを準備する

接続先、ロール、ウェアハウス、モデル名、必要なライブラリを準備します。

**成功の目印:**

```text
準備完了: TV_F1_PRESENCE_MODEL V2
```

### セル2: 予測に使うデータを準備する

5局の視聴データをテレビ1台につき1行へまとめ、予測に使う12項目を作ります。正解が分かっている2,000台を学習と評価に使います。

**成功の目印:**

```text
データ準備完了: 全体 20000台 / 学習・評価対象 2000台
```

あわせて、データの先頭5行が表示されます。

### セル3: モデルを学習・評価する

2,000台を次の3組に分け、ロジスティック回帰モデルを学習します。

| 用途 | 台数 |
|---|---:|
| 学習 | 1,200台 |
| 調整 | 400台 |
| 評価 | 400台 |

**成功の目印:**

```text
学習データ: 1200台 / 調整データ: 400台 / 評価データ: 400台
評価完了
```

評価指標も表で表示されます。この章では、モデルを学習して評価結果を確認できたことを体験します。

### セル4: モデルをSnowflakeへ登録する

学習したモデルに名前と版を付け、SnowflakeのModel Registryへ登録します。

**成功の目印:**

```text
モデル登録完了: TV_F1_PRESENCE_MODEL V2
```

続けて、登録したモデルの関数 `predict_proba` が表示されます。

### セル5: 登録したモデルで予測する

Notebook内のモデルではなく、Model Registryへ登録したモデルを使って20,000台を予測します。

**成功の目印:**

```text
予測完了: 20000台
```

あわせて、`DEVICE_ID`、確率、判定の先頭5行が表示されます。

### セル6: 予測結果を保存する

最初は `SAVE_RESULTS = False` のまま実行します。次のメッセージが表示されたら、保存確認ができています。

```text
保存する場合はSAVE_RESULTSをTrueに変更してください。
```

次に、同じセルの先頭を次のように変更し、もう一度実行します。

```python
SAVE_RESULTS = True
```

**成功の目印:**

```text
保存完了: BCAST_PLATFORM_HANDSON.ML.PREDICTIONS 20000行
```

## 3. Notebookサービスを停止する

保存まで完了したら、Notebook上部で次を操作します。

```text
Connected
  ↓
サービス名
  ↓
Suspend
```

**成功の目印:** 状態が **SUSPENDED** になります。

ここまで完了したら、[第4章 Streamlit](04_streamlit.md)へ進みます。
