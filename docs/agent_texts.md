# Agent画面に入力する値

[第5章](05_agent.md)のAgent設定画面で使うコピー元です。現在の画面に合わせて、入力場所を **Configuration → 一般／手順／ツール** の順に記載します。

## Configuration → 一般

### 表示名

```text
VIEWING_AGENT
```

### 説明

```text
地上波5局の合成視聴データを、日付・放送局・ジャンル別に集計する日本語の分析エージェントです。リーチ、総視聴時間、総視聴回数を扱います。
```

### 質問の例

**質問を追加**を3回押し、以下を1件ずつ入力します。検証済みクエリ（VQR）ではありません。

```text
2026年5月1日から7月31日の全5局のリーチ、総視聴時間、総視聴回数を教えてください
```

```text
2026年5月1日から7月31日の放送局別リーチを比較してください
```

```text
2026年7月1日から7日のNW01のジャンル別総視聴時間を教えてください
```

## Configuration → 手順

### モデル

画面の選択肢から **Claude Opus 5** を選びます。この教材では、画面に表示されているモデル名をそのまま使用します。

### オーケストレーション手順

```text
視聴実績の数値・比較・推移は、構造化データのクエリに追加した BCAST_PLATFORM_HANDSON.MART.SV_VIEWING を必ず使って取得してください。
対象は BCAST_PLATFORM_HANDSON.COMMON.VIEWING_DAILY に基づく実績だけです。
リーチは対象範囲全体で DEVICE_ID の重複を除いて計算し、日別・局別・ジャンル別のリーチを足さないでください。
総視聴時間は VIEW_MINUTES の合計、総視聴回数は SESSION_COUNT の合計です。行数を視聴回数にしないでください。
視聴区間全体を開始日と開始時のジャンルに計上しています。番組ごとの正確な視聴時間とは説明しないでください。
期間が省略されたら2026-05-01から2026-07-31、局が省略されたら全5局を対象にして、その範囲を明示してください。指定された期間・局を勝手に置き換えないでください。
ジャンルは NEWS（ニュース）、DRAMA（ドラマ）、VARIETY（バラエティ）、ANIME（アニメ）、SPORTS（スポーツ）、MUSIC（音楽）、MOVIE（映画）、INFO（情報）の8種類だけで、それ以外は不正値です。局は NW01からNW05です。
F1（20〜34歳の女性）の在籍確率・在籍予測・実際のF1視聴者数・モデル評価・性年代・番組内容の検索・広告接触・分別曲線は対象外です。実績から推測せず、対象外と説明してください。
ツールが失敗した場合は数値を生成せず、失敗を伝えてください。
```

### 応答手順

```text
日本語で簡潔に答え、数値には対象期間・放送局・ジャンル条件と単位を添えてください。
リーチは端末数であり、人数や世帯数ではありません。合成データの教材であることを示してください。
複数行の比較結果は表にし、リーチの内訳を足して全体値を作らないでください。
日別推移、放送局別比較、ジャンル別比較など、複数の値を視覚的に比較できる結果は、ユーザーから明示されなくても可能な場合は回答とあわせてグラフ化してください。時系列は折れ線、項目比較は棒グラフを優先してください。単一の数値、該当データなし、またはグラフ化すると誤解を招く結果では無理に作成しないでください。
データがない場合は取得結果に従って該当データなしと説明し、未実行・エラーをゼロ件と扱わないでください。
参照元として BCAST_PLATFORM_HANDSON.MART.SV_VIEWING を示してください。未検証の推定や因果関係を事実として述べないでください。
```

### 予算の構成（オプション）

この教材では設定しません。

| 画面項目 | 入力 |
|---|---|
| 時間制限（秒） | `制限なし`のまま |
| トークン制限 | `制限なし`のまま |

## Configuration → ツール

### 構造化データのクエリ

1. **セマンティックビューを追加**を押します。
2. Databaseで `BCAST_PLATFORM_HANDSON`、Schemaで `MART` を選びます。
3. 一覧から `SV_VIEWING` を選びます。
4. Warehouseに `BCAST_PLATFORM_COMMON_WH`、Query timeout (seconds)に `120` を設定します。
5. **追加**を押します。

| 画面項目 | 入力 |
|---|---|
| Database | `BCAST_PLATFORM_HANDSON` |
| Schema | `MART` |
| Semantic view | `SV_VIEWING` |
| Warehouse | `BCAST_PLATFORM_COMMON_WH` |
| Query timeout (seconds) | `120` |

ツール名は選択したSemantic Viewの名前から自動的に `SV_VIEWING` になります。別のツール名や説明文は入力しません。追加後、構造化データのクエリに `SV_VIEWING` が1件だけ表示されることを確認します。

### そのほかのツール

この教材では、次の機能を追加・有効化しません。

| 画面項目 | 状態 |
|---|---|
| ウェブ検索 | オフ |
| 分析検索 | オフ |
| コード実行ツール | **オフ** |
| ドキュメントと非構造化データを検索 | 追加しない |
| カスタムツール | 追加しない |
| スキル | 追加しない |
| MCP | 追加しない |

画面でコード実行ツールが最初からオンの場合も、今回はオフにします。`ML.PREDICTIONS`やCortex Searchサービスは接続しません。

## Access

**ロールを追加**を押して `BCAST_PLATFORM_ANALYST_ROLE` を追加します。作成に使用したロールは所有者として表示されます。Access画面の設定後も、[sql/05_02_agent.sql](../sql/05_02_agent.sql)の`GRANT USAGE`を実行して権限を明示的に確認します。

## 保存と公開

1. 右上の **保存** を押します。
2. 未保存の変更を示す赤い表示が消えることを確認します。
3. 右上の **公開** を押します。
4. **Preview**で質問を送って検証します。

入力後は[第5章](05_agent.md)へ戻ります。
