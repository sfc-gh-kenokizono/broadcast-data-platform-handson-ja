## 基本SQLの注意

- `01_basic.sql` は教材データを更新・削除しません。
- 共通マートの期待値はリーチ20,000台、総視聴回数1,050,000回、総視聴時間約12,511,642.266667分です。
- ジャンル別リーチを足して全体リーチにはしません。
- 結果キャッシュはクエリ履歴・プロファイルで確認し、速さだけで再利用と断定しません。
- 視聴区間のサンプルは7行を3区間へまとめます。`SOURCE_ROWS`は4、2、1です。本編データの定義は変更しません。

## 定期実行を設計するなら

この教材ではスケジュールを作成・有効化しません。運用では次の順序と制御が必要です。

| 段階 | 成功条件 |
|---|---|
| 入力 | データとコードの版が固定される |
| 局別 | `nw01`から`nw05`を各target・選択範囲・局別WHでbuildし、モデルとテストが成功する |
| common | 同じ実行回の5局がすべて成功した後にbuild・testが成功する |
| 公開 | common成功後だけ、後続処理が新しい実績を使う |
| 運用 | 失敗通知、再実行、二重起動防止、停止担当、未合格成果物の非公開化を決める |

以前の成功や残存テーブルを今回の成功とみなしません。MLの再学習・登録・推論や、固定文書を使う補足Searchは、この更新フローへ自動追加しません。
